## Reading the project

The README describes the current portfolio prototype. The specification and
historical planning documents also include future work; they are not a list
of completed features. Dashboard images contain synthetic demonstration data.
The mobile concept image is explicitly a design study.

The core boundaries are raw-data preservation, idempotent ingestion,
versioned analytics and explicit data egress. Start with ADRs 0003, 0006,
0009 and 0012 in the decision index for their rationale.
